# Code Of Conduct

This project expects respectful, constructive participation.

## Expected Behavior

- Be clear and professional.
- Assume good intent while staying precise about technical risk.
- Keep discussions focused on the project and user impact.
- Respect maintainers' time by providing reproduction steps, logs, and focused pull requests.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing private information, credentials, or tokens.
- Repeated off-topic, hostile, or spam-like comments.
- Deliberately submitting malicious code or misleading reports.

## Enforcement

Maintainers may edit, hide, or remove comments and may block contributors who violate this code of conduct.

# Security Policy

## Supported Versions

Security fixes are handled for the latest published release and active beta branch.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Active beta | Yes |
| Older releases | Best effort |

## Reporting A Vulnerability

Please do not open a public issue for vulnerabilities, exposed credentials, or private model access tokens.

Use GitHub private vulnerability reporting or contact the maintainer through GitHub with enough detail to reproduce and assess the issue.

Helpful reports include:

- Affected version or commit.
- Operating system and runtime context.
- Steps to reproduce.
- Expected and actual impact.
- Relevant logs with secrets redacted.

Do not include Hugging Face tokens, API keys, or local credential values in reports.
